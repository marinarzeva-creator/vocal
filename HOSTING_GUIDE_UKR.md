# 🚀 Інструкція: Як розмістити сайт на хостингу

Сайт **«Творчий простір Катерини Жанько»** створено як повністю автономний статичний веб-сайт. Він не потребує баз даних чи складних налаштувань серверів і може бути розміщений на **будь-якому українському або міжнародному хостингу**.

---

## 📦 Де знаходяться всі готові файли?

1. **Готовий ZIP-архів:**
   - Файл `vocal-studio-site.zip` (знаходиться в корені проєкту та в папці `public/`).
   - Його також можна завантажити в один клік прямо з сайту через кнопку **«Файли для хостингу (ZIP)»** у підвалі сторінки.

2. **Папка з усіма файлами:**
   - Папка `dist/` містить усі зібрані файли:
     - `index.html` — головна сторінка сайту з усіма блоками, піаніно, відгуками та прайсом.
     - `thank-you.html` — окрема сторінка подяки (**Thank You Page**), на яку автоматично перенаправляється клієнт після успішного залишення заявки (також доступна за адресою `/thank-you`).
     - `assets/` — швидкі оптимізовані стилі (CSS) та скрипти (JS).
     - `kateryna.jpg` — якісне фото викладача.
     - `.htaccess` — готовий файл конфігурації для серверів Apache/cPanel (забезпечує красиві посилання `/thank-you`, кешування та стиснення gzip).
     - `_redirects` — конфігурація для Netlify та Cloudflare Pages.

## 🛠️ Як завантажити файли на хостинг (3 простих способи)

### Варіант 1: Будь-який український хостинг (Хостинг «Україна», Hostinger, CityHost, FreeHost, HostPro) через cPanel або Файловий менеджер
1. Увійдіть у вашу панель керування хостингом.
2. Відкрийте **«Файловий менеджер» (File Manager)**.
3. Перейдіть до кореневої папки вашого сайту — зазвичай це `public_html` або `www/vash-site.com.ua`.
4. Завантажте файл `vocal-studio-site.zip`.
5. Клацніть правою кнопкою миші на архів і оберіть **«Видобути» (Extract / Розархівувати)**.
6. Переконайтеся, що файл `index.html` та папка `assets` лежать безпосередньо у папці `public_html`.
7. **Готово!** Ваш сайт відкривається за адресою вашого домену.

---

### Варіант 2: Безкоштовний хостинг Netlify (за 30 секунд без налаштувань)
1. Перейдіть на сторінку [app.netlify.com/drop](https://app.netlify.com/drop).
2. Розархівуйте `vocal-studio-site.zip` на своєму комп'ютері або візьміть папку `dist`.
3. Просто перетягніть папку у вікно браузера на Netlify.
4. Netlify миттєво надасть вам безкоштовний робочий сайт з SSL-сертифікатом (https).
5. За бажанням підключіть власний домен (наприклад `katyazhanko.com.ua`).

---

### Варіант 3: Vercel або GitHub Pages
- **Vercel:** Команда `npx vercel deploy --prod` або підключення через GitHub.
- **GitHub Pages:** Завантажте вміст папки `dist/` у гілку `gh-pages` або в папку `docs/` основного репозиторію.

## 📱 Як працюють сповіщення Telegram?
- Форми сайту відправляють заявки безпосередньо в Telegram через офіційний Telegram Bot API:
  - Ім'я клієнта
  - Номер телефону (з українським кодом +380)
  - Обраний месенджер (Telegram, Viber, Instagram, дзвінок)
  - Напрямок (Вокал, Фортепіано, Вокалотерапія, Пробне)
  - Бажаний день/час
- Щоб підключити вашого Telegram-бота:
  1. Натисніть на значок шестерні біля контактів на сайті.
  2. Введіть **Bot Token** від @BotFather та ваш **Chat ID**.
  3. Натисніть «Зберегти». Всі заявки миттєво приходитимуть вам у телефон!
- Також усі заявки надійно дублюються у локальну пам'ять браузера (Local Storage).

## 🎯 Як налаштувати рекламу та пікселі на Thank You Page?
Сторінка подяки має постійну URL-адресу:
- `/thank-you` (або `thank-you.html`)
- У Facebook Ads Manager / Google Ads налаштуйте конверсію (Lead) на відвідування URL, що містить `/thank-you`.
